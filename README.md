# SeriesWeb 📺

A simple and responsive web app for TV series enthusiasts.

## Features
* **Authentication**: Simple login validation.
* **Smart Search**: Find series by title with strict filtering.
* **Dynamic Details**: View plot summaries, genres, and posters.
* **Fully Responsive**: Optimized for PC (5 columns), tablets, and phones.

## Tech Stack
* HTML5
* CSS3 (Grid & Flexbox)
* JavaScript (ES6+ Fetch API)
* [TVMaze API](https://www.tvmaze.com/api)

## How to use
1. Open `index.html` in your browser.
2. Enter any credentials to log in.
3. Search for your favorite show!
